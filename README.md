# AI Engineering 101

A 45-day journey from zero to deploying a real AI application. 

## Current Progress
- **Week 1:** Python basics, API calls, Chatbots
- **Week 2:** ML basics, Overfitting, Gradient Descent, Transformers
- **Week 3:** Embeddings, ChromaDB, Chunking, RAG pipeline
- **Week 4:** LLM Evaluation, Golden Sets, LLM as a Judge

## The Final Project
A customer support RAG bot that answers questions from private documents and refuses to answer when it doesn't know.
